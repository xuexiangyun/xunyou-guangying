# 瞬游光影

面向主流第一人称射击游戏的本地网页高光剪辑 Agent。

## 更新公告

### 2026-10-23 · 多文件高光剪辑

以前一个任务只能喂一个录像，现在可以一次上传多个，各自找高光，最后合成一条成片。

- 单个任务最多 8 个 MP4 / MOV / MKV 文件，每个文件的时长上限仍按原规则单独校验
- 每个文件独立扫描画面与声音、独立排序候选、独立去重；两局录像各出现一个三杀，两段都会保留（跨文件不去重）
- 候选按文件顺序合并到一条时间线，成片顺序与上传顺序一致，不会把第二个文件的片段插到第一个文件前面
- 分析预算按文件分配，而不是所有候选挤在一个池子里抢名额，长录像不会被短录像挤掉
- 渲染时取所有源文件里最小的宽高作为目标尺寸，1080p 和 720p 混着传也不会放大发虚
- 网页上传支持多选与拖拽追加，重复文件自动跳过，超出 8 个会提示并忽略多余项；每个文件可单独移除，上传进度显示「正在上传 2/5：xxx.mp4」
- 任务列表里多文件任务显示为「A.mp4 等 3 个文件」，源文件大小、进度、取消和「清理并处理新视频」都按整个任务生效，会一并处理该任务的所有源文件
- 数据库结构升级到 v2（新增 `upload_ids_json`、`files_metadata_json`，旧的 `upload_id` 列保留），启动时自动迁移；旧的单文件任务照常可查、可下载，老接口传单个 `upload_id` 也仍然兼容

只剪一个文件时，用法和以前完全一样。

## 第一版能力

- 上传 MP4、MOV、MKV 横屏录像，单个任务最多 8 个文件（见上方更新公告）
- 最高 1920×1080，最长 2 小时，单文件最大 20GB
- 可选择具体游戏和游戏模式，也可以交给千问自动判断
- 内置彩虹六号、无畏契约、CS2、CS:GO、使命召唤、战地、三角洲行动、Apex、PUBG、守望先锋2、塔科夫、THE FINALS、穿越火线、光环和命运2等游戏配置档
- 支持回合制竞技、大逃杀、团队重生、战术撤离、目标、人质、炸弹（下包与拆弹）和单人战役
- 每个游戏和模式都有独立提示词规则，会把对应HUD、阵营、目标、胜负条件和高光证据交给千问，不只是页面标签
- 彩虹六号使用专属证据链：先核对当前视角的击杀归属与回合结果，再判断 Ace、1vX、连杀、首杀/补枪、穿墙/垂直打法、干员道具和下包/拆弹；失败残局、击倒或队友击杀不会被误标为翻盘
- 彩虹六号候选会额外返回事件类型、当前玩家击杀数、残局人数、回合/目标结果、可回看时间戳和七维评分
- 彩六高分候选会进行第二次独立审核，专门排除赛事回放、干员选择、摄像头/无人机和纯胜利结算误判
- FFmpeg 在本地按秒扫描声音和画面，只筛选少量候选片段
- FFmpeg 将高分候选压缩成约30秒、7MB以内的分析副本
- Qwen3-Omni-Flash 同时理解候选片段的画面、HUD、游戏音效、语音和战斗结果，优先使用720p分析副本，不上传完整录像
- 千问可返回“没有明确高光”，低于50分的普通片段不会进入成片
- 每段候选会生成主分类、辅助分类、证据、置信度和高光时间点
- 自动组合一条最长 30～120 秒的 16:9 高光成片；目标时长是上限，不会为了凑时长加入普通画面
- 每段使用模型给出的clip_start/clip_end边界，保留必要前因、完整动作与回合结果
- 严格/均衡/宽松分别使用70/60/50分入选门槛，识别强度不再通过减少搜索候选来实现
- 字幕支持智能、关闭和始终开启三种模式，默认使用智能模式
- 智能模式根据千问对语音价值的判断，只为反应、交流和对话重要的高光启动本地 Whisper
- 纯枪法、纯操作且没有重要语音的成片会跳过字幕，减少等待和画面遮挡
- 网页显示上传、分析、剪辑和字幕进度
- 每两个高光片段之间使用约0.35秒的快速斜纹转场，声音同步短交叉淡化
- 上传后采用画面/声音并行扫描、2路千问候选分析和单次成片编码，减少长录像等待时间
- 本机上传分块提升至32MB，进度条会显示候选准备与并行分析的实际进展
- 运行中的任务可随时取消，正在执行的 FFmpeg 进程会被安全终止
- 网页提供历史任务列表，可下载已完成成片、清理单个任务或一键清理全部历史数据
- 启动时会自动修复因移动项目目录导致的路径失效，并清理无引用的临时文件
- 成品可网页预览、下载，也会保存在本地

## 使用

首次使用前请确保已安装：

- Python 3.11
- FFmpeg（`ffmpeg` 与 `ffprobe`）
- Node.js 与 npm（用于构建网页）

缺少时 `install.command` 会尝试通过 Homebrew 自动安装。

第一次使用：双击 `install.command`。

以后使用：双击 `start.command`，浏览器会打开：

```text
http://127.0.0.1:8503
```

首次使用时在网页的一次性设置区填写阿里云百炼按量付费 API Key 和创建 Key 时显示的 API Host：

- 验证成功后，凭证区自动隐藏，主页面只显示“千问AI已连接”
- API Key 通常以 `sk-` 开头，保存在本机权限为 `600` 的私有配置文件中，不写入任务数据库或前端代码
- API Host 应以 `/compatible-mode/v1` 结尾，并与 Key 一起保存在本机私有配置中
- API Key 与 API Host 必须来自同一地域，推荐统一选择华北2（北京）
- 所有剪辑任务强制使用 Qwen3-Omni-Flash；未完成千问配置时不能开始剪辑

## 数据目录

- 上传文件：`data/uploads`
- 输出成片：`data/outputs`
- 临时数据：`data/temp`
- 任务数据库：`data/db/xunyou.sqlite3`
- 千问私有配置：`data/config/qwen_credentials.json`

成片完成后可以在网页点击“清理并处理新视频”，删除该任务的上传副本、临时文件和输出文件。

## 开发结构

- `frontend`：React + Vite 网页
- `backend/app/main.py`：FastAPI 接口
- `backend/app/services/video.py`：本地信号分析与 FFmpeg 剪辑
- `backend/app/services/qwen.py`：Qwen3-Omni-Flash 音视频分析
- `backend/app/services/subtitles.py`：Whisper 与跨平台字幕渲染
- `backend/app/services/pipeline.py`：完整剪辑流水线
